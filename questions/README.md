# Questions

**You are here. Start with the question that has your attention.**

This folder is the natural-language doorway into `.yawn`. You can enter from
any question below. Each path points into the same protocol without requiring
you to understand the whole repository first.

| Question | What it reveals |
| --- | --- |
| [What is this?](what-is-this.yawn) | The smallest honest definition of `.yawn` |
| [Where am I?](where-am-i.yawn) | Your current location, context, and permissions |
| [What can I do next?](what-can-i-do-next.yawn) | A bounded move, including the choice not to move |
| [What is still unresolved?](open-questions.yawn) | Missing information that must remain visible |

You can answer in ordinary language. A person or AI may map the answer into a
`.yawn`, but skipped answers remain open questions and AI output remains an
inference rather than authority.

```text
question
-> visible answer or visible gap
-> boundary
-> move or deliberate pause
-> proof
-> replay
```
