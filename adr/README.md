# Architecture decision records

ADRs preserve why a durable implementation choice was made after the broader
protocol semantics are understood. RFCs decide what the protocol means; ADRs
record how this repository realizes it.

Status values: `proposed`, `accepted`, `superseded`, `rejected`.

Each ADR records context, decision, alternatives, consequences, evidence,
authority, and superseding links. Accepted ADRs are append-only historical
records; corrections create a new ADR that supersedes the old one.
