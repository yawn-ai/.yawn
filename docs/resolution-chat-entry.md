# Resolution and in-place capture (draft)

The proposed interface contract is [`../interface/resolution-chat-entry-v0.1.yawn`](../interface/resolution-chat-entry-v0.1.yawn).

A Yawn keeps its identity while its participant chooses a view and a level of displayed detail. Glance, Working and Inspect are reversible presentation settings, not stages of knowing, degrees of truth, permission, or task difficulty. Turning up detail reveals existing material; refining a model is a separate operation requiring new distinctions, correction or evidence. Missing material stays missing.

Opening chat places the existing text/file composer inside the same projection. New opens an explicitly targeted draft in that same frame. A server-confirmed private save, not a navigation or a tap, establishes a persisted record. Source words, interpretations, participant responses, goals, grants and outcomes stay distinct.

## Adoption and proof

This is an additive proposal. It does not modify the stable schemas or the product's existing protocol lock. First implement and prove the shared product behavior. Then reconcile the root `readme.yawn` and human `README.md` with an explicitly proposed interface link, preserving their current statements and prior revisions. A maintainer must separately decide when to merge or promote it. Do not copy private motivating material into documentation or fixtures.

No production runtime, authenticated save/reload, psychological outcome, or browser conformance is certified by this document.
