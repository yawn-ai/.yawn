# Resolution and in-place capture (draft)

The proposed interface contract is [`../interface/resolution-chat-entry-v0.1.yawn`](../interface/resolution-chat-entry-v0.1.yawn).

A Yawn keeps its identity while its participant chooses a view and a level of displayed detail. Glance, Standard and Deep are reversible presentation settings, not stages of knowing, degrees of truth, permission, or task difficulty. Turning up detail reveals existing material; refining a model is a separate operation requiring new distinctions, correction or evidence. Missing material stays missing.

Opening chat places the existing text/file composer inside the same projection. New opens an explicitly targeted draft in that same frame. A server-confirmed private save, not a navigation or a tap, establishes a persisted record. Source words, interpretations, participant responses, goals, grants and outcomes stay distinct.

## Adoption and proof

This is an additive proposal. It does not modify the stable schemas or the product's existing protocol lock. First implement and prove the shared product behavior. Then reconcile the root `readme.yawn` and human `README.md` with an explicitly proposed interface link, preserving their current statements and prior revisions. A maintainer must separately decide when to merge or promote it. Do not copy private motivating material into documentation or fixtures.

No production runtime, authenticated save/reload, psychological outcome, or browser conformance is certified by this document.

## Reconciliation with situated moments

The current application vocabulary is `glance`, `standard`, `deep`. Earlier proposal labels `working` and `inspect` are read aliases only. Do not import the public scenario runtime as a private-record implementation. Its examples are illustrative; their source IDs, timestamps, and action permissions do not transfer to a live participant.

View, resolution, time and scope are independent presentation coordinates. Task difficulty is a property of an activity. They need not all become visible controls. Bind each projection to one root snapshot and an explicit source-version manifest; related records may have different revisions. Apply current access rules even when replaying older snapshots. Pin an active inspection long enough to use it; show new revisions without silently moving the reader's place.

Ordinary rendering and reading already permitted material are not additional analysis grants. New generation, external actions or costs follow their own operation and authorization flow; a dial movement does not trigger them. Existing scoped grants may be reused, not widened.

Protocol completion does not complete the product. Shared entry, in-place text/file capture, genuine per-view detail, attributable corrections, authenticated private save/reload, and independent browser/privacy proof remain required. A public synthetic fixture tests mechanics; it does not replace a private owner-session acceptance test or establish learning.
